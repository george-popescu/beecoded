## Platform
web

## Stack
The plugin uses Node.js. Coamb, its Board, is a self-contained local HTML artifact with vanilla JavaScript, CSS and data-driven SVG; no server, CDN or frontend dependency is required.

## Users and purpose
Developers coordinating Claude Code and Codex work need to see recorded delivery progress, remaining evidence and attributable consumption together. The Board is observational: it does not approve, execute or publish work.

## Capabilities and constraints
The approved upgrade includes work status, session costs/tokens/time, scoped historical import, exports, optional hooks, debt inventory and capability guidance. Telemetry is opt-in and metadata-only. Missing values remain unknown; API-equivalent costs are not subscription invoices. Project identity must not rely on a display name. Existing completion and recovery contracts remain authoritative for recorded workflow state.

## Brand commitments
The user chose the name Coamb for the Board and a dark compact dashboard close to Ponytail, with clear tables and charts. Visible branding is Coamb alone, with an amber hexagonal C mark and no attribution line. Nectar remains the plugin name and CLI namespace. Use direct English product copy without performance claims.

## Evidence
Doctor provides recorded work state. Host telemetry supplies only recognized fields with provenance. Preview data must be explicitly synthetic. Neither source proves unobserved product behavior.
