# Capture

Zero-friction idea capture. One line, then back to work.

## Protocol

Read relevant entries in `docs/work/backlog.md`. Append a concise idea or enrich
the existing matching entry when it is clearly the same request; preserve unrelated
entries. Confirm briefly and return to active work. Capture unresolved meaning
without turning it into a design session. Do not promise a fixed execution time.

## Line format

```
- YYYY-MM-DD <idea> (context: <what triggered it>; revisit when: <condition or "anytime">)
```

If `docs/work/backlog.md` does not exist, create it with a `# Backlog` heading first, then append the line.

## Surfacing and cleanup

Read relevant backlog entries when shaping related work. Remove a satisfied entry
only as part of authorized reconciliation; keep unrelated or ambiguous ideas.
